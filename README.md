# My Stock Watch v0.5

日本株4社・米国株6社の株価・ニュースを確認するStreamlitアプリです。

## v0.5の変更点
- OpenAI API呼び出しを削除。APIキー不要。
- 選択銘柄のニュース見出しと記事URLを含むChatGPT向け質問文を表示。コード欄右上からコピーしてChatGPTに貼り付けます。
- 記事ごとの質問文も用意。ChatGPTを開くリンクを追加。
- お気に入りと株価アラート（アプリ表示時の日足終値で判定）は維持。

## Androidからの更新
1. このZIPを展開。
2. GitHubの `Keina-1012/my-stock-watch` のルートにある `app.py` を新しい `app.py` で上書きしコミット。
3. `requirements.txt` も上書きするとOpenAIライブラリのインストールが不要になります。
4. Streamlit Cloudの自動再デプロイ後にアプリを再読み込み。

## 注意
- ChatGPTはリンクから開きます。質問文は自動送信されないためコピーして貼り付けてください。
- ニュース見出し・RSSリンクは未検証です。ChatGPT側で情報の確認を依頼してください。
- 株価アラートはプッシュ通知ではありません。取得可能な日足終値でアプリ閲覧時に判定します。
- お気に入り・アラート設定はURLのクエリパラメータに保存されます。URLを共有すると設定も共有されます。
- 株価データは非公式のyfinance経由であり、遅延・欠落する場合があります。
